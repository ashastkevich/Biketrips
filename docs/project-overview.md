# BikeTrips: краткое описание проекта

BikeTrips - сервис для поиска, организации и участия в совместных велопоездках. Проект ориентирован на Россию и страны СНГ, а первая версия задумана как mobile-first web-интерфейс с поддержкой Telegram-бота.

Главная идея продукта - заменить разрозненные объявления о поездках в Telegram-чатах, VK-группах, личных каналах и таблицах единым местом, где у каждой поездки есть понятная карточка, актуальная ссылка, маршрут, список участников и уведомления об изменениях.

Ключевые аудитории:

- организаторы велопоездок, клубы, тренеры, магазины и локальные лидеры сообществ;
- участники-любители и новички, которым важно быстро понять, подходит ли поездка по темпу, сложности, маршруту и формату;
- спонтанные райдеры, ищущие поездку сегодня, завтра или в ближайшие выходные.

MVP должен позволять пользователю с подтверждённым номером телефона быстро создать поездку, получить публичную ссылку, управлять участниками и отправлять обновления. Участник должен видеть ближайшие поездки, фильтровать их по городу, дате, темпу и уровню, открывать карточку поездки и записываться после простой регистрации.

Город выбирается из общего справочника и сохраняется как последний выбор пользователя. Каталог загружает поездки только выбранного города, а точное место старта и его координаты хранятся отдельно. Стабильный slug города передается в URL, например `/?city=moscow`.

## Роли и права доступа

- Гость может просматривать и искать поездки, но не может записываться или создавать их.
- Зарегистрированный пользователь может записываться на поездки независимо от способа регистрации: Telegram, телефон, почта или другой подключённый провайдер.
- Зарегистрированный пользователь может создавать поездки только после подтверждения номера телефона в профиле.
- Администратор имеет системные права управления и доступ к административным операциям.

«Участник» и «создатель поездок» — не отдельные роли, а возможности зарегистрированного пользователя. Подтверждение телефона расширяет права пользователя и не создаёт новый тип аккаунта.

Важные сущности проекта:

- лента ближайших поездок;
- карточка поездки с темпом, уровнем, дистанцией, маршрутом, покрытием, форматом `drop/no-drop`, правилами и снаряжением;
- форма создания поездки;
- запись участника через Telegram или веб-форму;
- управление списком участников, лимитом мест и листом ожидания;
- Telegram-бот для подтверждений, напоминаний и уведомлений.

Текущий репозиторий содержит PRD `biketrips-prd-v1.md`, Next.js-приложение в `apps/web`, API, Telegram-бот и shared-пакеты монорепозитория. PRD стоит считать основным источником продуктовых требований, этот файл - коротким контекстом для быстрого входа в проект, а `docs/architecture.md` - источником принятых технических решений по стеку и архитектуре.

Инструкции по локальному запуску web, API, PostgreSQL и Redis находятся в
`docs/local-development.md`. Для базы проекта принят Docker Compose; локальный
Homebrew PostgreSQL на порту `5432` одновременно запускать не следует.
